# Password Checker 🔐

A simple Password Checker web application built using Flask, HTML, CSS, and JavaScript.  
This project checks password strength and helps users create secure passwords.

---

## 📌 Features

- Password strength checking
- Simple and clean UI
- Flask backend integration
- HTML, CSS, JavaScript frontend
- Beginner-friendly project structure

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

### 1.## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/password_checker.git
```

### 2. Go to project folder

```bash
cd password_checker
```

### 3. Install Flask

```bash
pip install flask
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

http://127.0.0.1:5000
